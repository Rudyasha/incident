# Одна операция. Две попытки. Разные состояния.

Расследование инцидента при завершении обмена ковров: мобильное приложение → Lincore → Kafka → 1С:ERP.

**Задача 1 · Анализ инцидента и локализация**
</div>

!!! abstract "Главный вывод"
    По данным из переписки первая попытка привела к успешному созданию счёта. Повтор с тем же `exchange_id` создал вторую запись и событие, получившее `duplicate_document`. Предварительно проблема локализуется в обработке повторов; причина `invoice=N/A` в реестре требует отдельной проверки.
