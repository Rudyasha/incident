# О задании

Практическое задание по расследованию инцидента в приложении водителя-экспедитора: обмен ковров, Lincore и интеграция с 1С:ERP.

При завершении обмена приложение показало ошибку сохранения. Водитель повторил действие, а позже финансовый реестр показал отсутствие счёта.

В [Задаче 1](task-1.md) разобраны возможные причины, признаки в артефактах и предварительное заключение. Основной вопрос: почему система показывает ошибку, если первое сообщение уже привело к созданию счёта?
